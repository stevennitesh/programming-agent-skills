# Global Codex Instructions

## Skill Pack Bootstrap

Repository instructions supply local facts and constraints. Skills provide
the contracts for selected workflows; no standard document tree is required.

- **Route:** Use specialist skills when the task needs them. Suggest explicit-only workflows when useful; start them when the user requests them. Ordinary coding needs no skill pipeline.
- **Setup:** Suggest `$repo-bootstrap` for initial guidance or requested setup migrations. Use `$context-hygiene` for relevant maintenance of existing context; a missing preferred document alone does not block coding.
- **Boundary:** Keep project facts, accepted decisions, and workflow rules at their existing owners. General coding advice does not require a separate contract.
