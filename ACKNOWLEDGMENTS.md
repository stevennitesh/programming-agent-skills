# Acknowledgments

I did not invent every good idea in this pack. It draws on public work from:

- [Matt Pocock's engineering skills](https://github.com/mattpocock/skills),
  especially short named workflows, issue shaping, tight implementation loops,
  and clear instructions for agents.
- [pstack by poteto](https://github.com/cursor/plugins/tree/main/pstack),
  especially its focus on understanding code deeply, designing from clear data
  shapes, keeping interfaces small, and proving behavior through real callers.
- [Ponytail by Dietrich Gebert](https://github.com/DietrichGebert/ponytail),
  especially its YAGNI ladder: avoid building when possible, reuse the
  codebase, prefer language and platform capabilities, and write only the code
  the task needs.
- [Superpowers](https://github.com/obra/superpowers), especially skill-based
  planning, debugging, verification, and delegated development workflows.
- [Andrej Karpathy's observations on coding agents](https://x.com/karpathy/status/2015883857489522876),
  especially the warnings about hidden assumptions, unnecessary abstractions,
  unrelated edits, and work that is never meaningfully verified.

These are influences, not affiliations. This repository is independent and is
not endorsed, sponsored, or maintained by the people or projects above.
