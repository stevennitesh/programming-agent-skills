# Behavioral Wording Controls

Use this procedure only for a claim that exact skill wording changes
invocation, judgment, action, context loading, Return, or completion.

Freeze the task, full context, model, host, reasoning configuration, tools,
authority, evidence, runtime, and rubric before sampling. Keep candidate
language, conclusions, and prior outputs out of control contexts. Compare
uncontaminated direct controls whose only arm difference is the exact runtime
wording under test.

Inspect every output against the fixed rubric. Treat strings, headings,
template echoes, and deterministic structure as structural evidence only.
Report the tested bounds, unavailable evidence, protocol deviations, and
residual transfer risk without extrapolation.
