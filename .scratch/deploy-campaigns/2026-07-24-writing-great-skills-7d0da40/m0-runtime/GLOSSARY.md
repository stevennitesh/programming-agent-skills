# Skill-Authoring Vocabulary

Load this file only when invocation, information hierarchy, pruning, or
completion vocabulary affects the work.

- **Invocation:** the observable request or caller condition that admits the
  skill, together with its closest exclusions.
- **Information hierarchy:** common guidance stays inline; branch-only
  guidance is reached through a pointer that names both its target and trigger.
- **Pruning:** removing only wording without an intended-behavior or required
  local-contract owner while retaining every behavior-changing clause.
- **Completion:** the terminal state after ownership, proof, mutation
  read-back, and preservation are complete and before a foreign lifecycle
  phase begins.
