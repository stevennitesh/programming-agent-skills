# Tracker setup

Use for requested tracker configuration or guidance for established tracking.
A Git remote alone does not establish that issues are used.

## Configuration contract

Preserve the chosen provider even when it differs from Git hosting. Resolve an
unsettled choice from the request or repository evidence, asking only when needed.
Record the exact hosted project or durable local path; do not choose Local
Markdown merely because there is no remote.

Adapt the applicable representation:

- [GitHub](../templates/issue-tracker-github.md)
- [GitLab](../templates/issue-tracker-gitlab.md)
- [Local Markdown](../templates/issue-tracker-local.md)

The seeds' closure policy, request surfaces, relationship modes, and local paths
are starting choices, not provider requirements. Preserve established choices or
select suitable defaults within the setup request. In the adopted guide, replace
setup commentary with the exact project or paths and settled configuration, and
keep the operational guidance consistent with it.

When role mapping is needed, adapt [the label seed](../templates/triage-labels.md)
to existing equivalent values. Confirm that the configured relationships, claims,
and closure behavior are supported by the service and available tools; convenience
alone does not justify changing representation.

The consuming workflow owns readiness, claiming, transitions, and completion
evidence. Configuration does not make tickets mandatory for direct coding.

## Effects and completion

A local guide or label mapping does not create remote state. Perform authorized
remote changes and read them back; otherwise identify what remains unverified or
unconfigured. For Local Markdown, keep the durable tracker path versionable,
correcting conflicting ignore rules only within setup authority. Example tickets
or commits are not needed to prove the layout.

Finish when future agents can locate the tracker and use its configured
representation, with local configuration distinguished from verified remote
state and tool capability.
