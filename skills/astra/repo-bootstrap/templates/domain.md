# Domain docs

## Route

When domain meaning or an accepted decision affects the task, read the relevant
maintained domain context and decision records for this repository. Preserve their
terminology and distinguish accepted meaning from proposals and observed
implementation.

Missing preferred records are not automatically blockers. Resolve consequential
meaning from its actual owner or the user when the available context is
insufficient.

Repo-bootstrap configures where future agents find domain guidance; it does not
invent domain content. Use the repository's domain-shaping method when
clarification or durable reconciliation is requested.

Do not create empty context files, duplicate accepted decisions, or restore
retired routes merely to satisfy this template.
