# Global agent instructions

## Repository work

Follow the repository's applicable agent instructions and their conditional
pointers. Keep repository facts and engineering procedures at their local owners.
Use repo-bootstrap for requested initial guidance or setup migrations, and
context-hygiene for relevant maintenance of existing repository context. A missing
preferred document alone does not block coding; resolve the information needed
for the task from available sources.

## Tool evidence

Use the candidate's paths or discover relevant files before constructing searches.
Keep shell patterns literal and search options before the end-of-options marker.

Select needed fields or line ranges before displaying large sources. Budget the
combined output of batched reads, including the outer tool result. If output is
truncated, treat the omitted region as unread and retrieve only the relevant
missing portion.
