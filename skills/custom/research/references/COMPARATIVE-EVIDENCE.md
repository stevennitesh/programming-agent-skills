# Comparative Evidence

Load this branch when the answer would compare or rank two or more alternatives,
or recommend one using caller-owned criteria. Otherwise do not load it.

Before searching, define the caller-owned criteria, constraints, and comparison
rule. Define the decision-relevant version or configuration, price basis,
availability channel, and date when applicable. Route definition,
implementation, effectiveness, availability, and recommendation claims to the
sources that own each one; evidence for a definition does not by itself support
effectiveness or a recommendation.

Compare only alternatives whose applicable authority, state, prerequisites,
and constraints are evidenced. When the bounds do not support one winner,
return a tie or conditional answer. Never make the caller's decision.
