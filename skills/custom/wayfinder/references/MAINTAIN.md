# Maintain

Load only when Orient selects `Maintain` for one deterministic change requiring
no resolver judgment or ticket outcome: consequence-only representation repair,
a proved wait or blocker transition, or a fog trigger that now makes its
question sharp. Otherwise do not load it.

1. **Bound.** Show the exact evidence, delta, fog dispositions, allowance use,
   and resulting condition. Obtain destination-owner approval only to increase
   the allowance or change the approved destination packet.
2. **Apply.** Run the Mutation Gate with the map claim and make only the
   determined correction or liveness transition.
3. **Reconcile.** Apply no substantive ticket outcome.
4. **Complete.** Read back affected state, allowance, and frontier; let the
   Mutation Gate release the claim, prove absence, and Orient.

Return the verified deterministic delta, no ticket outcome, no retained claim,
and the resulting condition.
