# Quick Override

Use when the maintainer names the exact target state.

Read current roles and enough source context to produce the required comment or
brief. Skip ordinary request verification, redundancy screening, and shaping.

The command selects the named outcome, not an unseen mutation packet. Build the
complete packet and use the universal approval, refresh, mutation order,
read-back, partial-failure, and Return envelope in [SKILL.md](SKILL.md). Keep
the normal ready brief, disclaimer, `.out-of-scope/`, and close gates.

For a ready state, cite already-established verification or record
`maintainer-override`, the skipped verification, residual uncertainty, and
delivery proof still required. Reuse an existing brief only after it passes
the current Ready Gate.

For `implemented`, require an explicit label-correction request and existing
closeout evidence.

## Completion

Complete only when the exact approved packet is applied and read back, both
role invariants hold, every required post, brief, or rejection record exists,
and the typed triage packet is returned.
