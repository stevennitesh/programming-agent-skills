# Architecture decision records

Read the relevant current owner first. ADR history is optional context, not a
prerequisite for ordinary work.

| When you need… | Read… |
| --- | --- |
| Current pack composition and rationale | [Astra design brief](../astra/design-brief.md) |
| Repository purpose, source boundaries, or terminology | [CONTEXT.md](../../CONTEXT.md) |
