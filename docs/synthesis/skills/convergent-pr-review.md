## Intended Contract

`convergent-pr-review` is the root-owned terminal release gate for one
immutable local pull request, release candidate, or caller-bounded high-risk
diff. It captures one complete review snapshot, traces Standards and the
caller-authorized Spec separately, obtains direct fresh-context candidate
review when capacity permits, lets only the root admit findings after direct
verification, and returns exactly one read-only decision.

| Axis | Settled minimum |
| --- | --- |
| Outcome | One Lock-usable decision for the exact immutable snapshot, with admitted findings, coverage, skips, and residual risk. |
| Invocation | Implicitly invocable for one local PR, release candidate, or caller-bounded high-risk diff selected for independent review. |
| Exclusions | Ordinary branch, WIP, staged, or since-X review belongs to `$review`; immutable repository-baseline audit belongs to `$audit-codebase`; implementation, Repair, tracker/PR mutation, merge, publication, and delivery remain outside. |
| Root authority | Only the top-level root pins, plans, dispatches, owns the ledger, verifies, admits, reconciles, decides, and Returns. |
| Caller authority | The caller owns the Charter, commitment boundary, fixed point when supplied, target, Spec requirement, Source Trace, required proof, mode inputs, carried IDs, Repair delta, risk acceptance, mutation, and successor snapshots. |
| Reviewer authority | A direct reviewer receives one factual immutable brief, performs safe read-only verification, and returns candidates; it never mutates, spawns, sees peer conclusions, admits, decides, or starts a successor. |
| Safety | Files, Git state, dependencies, trackers, PR state, external systems, and successor snapshots remain unchanged. Unsafe or unavailable verification becomes a named evidence gap. |
| Modes | `initial`, `remediation`, and `assurance` retain the exact Prompt 1 inputs and bounds. |
| Judgment | Standards and Spec stay separate; findings use the shared five-gate contract; optional advisories stay severity-free and decision-neutral. |
| Capacity | At least two valid fresh completed reviewers is normal. The exact one-fresh and zero-fresh root fallback rows disclose reduced confidence and never permit plain `pass`. |
| Decisions | `pass`, `pass with residual risk`, `blocked`, or `incomplete`. `blocked` requires an admitted blocking finding on a current snapshot. An unresolved candidate, dispute, required evidence gap, protocol failure, or drift is `incomplete` unless a separate admitted blocker already establishes `blocked`; uncovered coverage remains explicit. |
| Completion | Every required axis/lens is covered or blocks; every candidate and carried ID is disposed; drift passes; one internally consistent packet returns with mutation and successor authority `none`. |

No research result exposed a missed minimum authority, safety, compatibility,
