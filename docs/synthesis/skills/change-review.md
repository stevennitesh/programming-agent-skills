# Change Review Synthesis

Status: current runtime summary.

Runtime authority is `skills/custom/change-review/`.

Change Review owns read-only judgment of one selected branch, WIP, staged or
since-X diff, PR, or fixed implementation candidate. Its ordinary path pins the
inspected content, traces accepted behavior and repository standards through
real callers, verifies concrete finding candidates, and returns prioritized
findings or `No findings` without mutation.

`FINDING-CONTRACT.md` admits only anchored, reachable, directly evidenced,
consequential, and proportionate findings. Generic smell catalogs, reviewer
agreement, and preference do not establish a defect.

When an invocation supplies `Formal review: yes`,
`references/FORMAL-REVIEW.md` adds required-Spec handling, reviewer-independence
evidence, bounded remediation review, and one terminal decision for the fixed
candidate. Implement and Parallel Implement own the condition-triggered
dispatch, repair, proof rerun, and successor candidate. High Assurance Review
remains an explicit-only two-lane coordinator and consumes the same compact
finding admission contract.

Implementation-worker profiles remain with implementation dispatch. Review
roles are semantic and use their review owner's fresh-context and separation
rules; Change Review does not validate model transport or report runtime
receipts. Neither ordinary nor formal review grants mutation, release,
acceptance, repair, or successor authority.
