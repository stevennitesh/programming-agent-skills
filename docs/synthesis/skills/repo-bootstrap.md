## Intended Contract

`repo-bootstrap` is an explicit-only reconciliation owner. Given one bounded
target repository and caller-owned inspection or mutation authority, it
observes every applicable setup surface, compares actual state with the
supported setup contract, proposes one exact owned delta, waits for approval,
preflights it, reconciles only approved setup-owned state, provisions only
missing required labels, rereads every authoritative mutation, validates the
complete surface, and returns a verified report or exact partial-failure
packet.

It preserves compatible local choices, foreign content, unrelated work, the
Git index, and `HEAD`. It does not choose the engineering route, answer
research questions, design modules, slice tickets, create domain truth, own
work-item lifecycle, install the pack, deliver Git state, or resume a caller.
