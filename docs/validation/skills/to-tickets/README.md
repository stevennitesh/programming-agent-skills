# To Tickets Validation

This directory owns per-skill validation evidence for `to-tickets`.

Historical campaigns under `campaigns/` retain their original manifest schema,
runtime labels, decisions, provenance, and tested bounds. Their placement here
does not admit them into a Fresh Composition Epoch, upgrade them to manifest
v2, or establish current efficacy.

Evaluation directories under `evals/` use stable `EV-...` identities.
