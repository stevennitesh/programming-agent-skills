# Audit Codebase Lean Navigation Behavior Evaluation

Date: 2026-07-28
Decision: `accept`

## Registration

- Contribution mode: `quality-lift`
- Registered deficit: report-wide drift outside a selected candidate and its
  subsystem blocks Analyze even when the candidate Source Trace is unchanged.
- Entry-positive input: uniquely selected
  `ro-c02-source-budget-coverage`, current candidate evidence, and unrelated
  documentation-only report provenance drift.
- Wrong condition: `ro-c02` ambiguously matches two presented candidates.
- Protected-depth input: the current source-budget candidate with six ordered
  roots, two Greenhouse roots, a budget of five, silent SmartRecruiters
  omission, and no `run.json` reconciliation.
- Authority: read skill text and fixed evidence; no repository, report,
  downstream, installation, or Git mutation.
- Host: Codex Desktop with fresh-context agents. Exact model, token, latency,
  and cost telemetry were unavailable.

## Rubric

Entry-positive samples must revalidate the selected current Source Trace,
ignore unrelated drift, record a validity judgment, and start no downstream
work. Wrong-condition samples must reject the ambiguous candidate without
choosing or substituting another objective.

Protected-depth samples must cover current shape and cost; Keep; smallest
sufficient, structural, and replacement alternatives; recommendation and
rejections; contracts and decisions; Responsibilities, Interfaces, Seams, and
Proof Seams; compatibility, migration, cutover, and rollback; proof; and
residual risk.

## Variance And Limits

One H1 entry-positive response said `Report update: updated` despite the
evaluation's no-write instruction; no file changed. The other four reported
the report unchanged. This is bounded Return variance in a simulated
publication-disabled task, not a navigation, analysis-depth, authority, or
mutation regression.

The evaluation used fixed verified evidence and did not perform a live HTML
publication. The package helper's atomic replacement, collision, unsafe
fragment, marker, target, and overlap behavior is covered by executable tests.
