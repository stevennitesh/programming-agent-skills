# Research Cards

`docs/research/skill-pack-composition/cards` is the canonical owner directory
for schema-valid `RC-NNNN` Research Cards. Cards are evidence records, not
adoption or H1 decisions.

Each Card is canonical Markdown with one complete schema-version-1 YAML
frontmatter record. The filename equals `card_id`; exact bytes determine the
versioned fingerprint. Claims use `<card-id>-C<NN>` and point to stable
`SRC-NNNN` source records embedded in the Card. Do not mint a Card by
converting historical material without the owning research workflow.

The parent [README](../README.md) owns catalog admission, retrieval, alias,
relation, index, and finite-session rules.
