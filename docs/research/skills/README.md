# Per-Skill Research

`docs/research/skills` owns fresh per-skill research packets with stable
`RP-<skill-at-mint>-YYYYMMDD-NN` identities. A skill directory routes its
packets; synthesis alone decides whether evidence contributes to H1.

For a Fresh one-skill Deploy campaign, use
`<skill>/RP-<skill-at-mint>-YYYYMMDD-NN.md` as the manifest v2
`semantic.pointers.research_packet`. The packet stays independent and finite:
problem-first evidence, Catalog results, bounded retrieval, and at most one
named gap. It does not contain H1 or claim-adjacency decisions.
